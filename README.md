# Hazem Gomaa Ali — Portfolio

A responsive Apple-inspired liquid-glass portfolio for Hazem Gomaa Ali, Full Stack .NET Developer.

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Included
- Dark / Light mode
- Responsive layout
- Profile image
- Bookly project gallery
- Students Information Dashboard
- Training and education
- GCI certificate viewer
- Downloadable CV
- LinkedIn, email and phone links
